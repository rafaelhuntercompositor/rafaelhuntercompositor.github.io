# Hunter Game Studio — Last Dawn Mobile

Aplicativo Android experimental com WebView e controles touchscreen nativos.

- O jogo é carregado do itch.io, portanto **exige internet**.
- Direcional: setas; B: correr (Z); A: agir (X); C: mapa; II: pausa (Enter).
- Esta versão é um teste não oficial, não foi validada em aparelho real.
- Apenas a interface está incorporada no APK; os arquivos originais do jogo continuam hospedados no itch.io.
- Compilar: Gradle 8.11.1 + JDK 17 + Android SDK API 36, `gradle :app:assembleDebug`.
- A versão debug é instalável para testes, mas não está pronta para publicar na Play Store.
- Como o jogo é um fan game baseado em uma obra de terceiros, a publicação comercial requer atenção a direitos autorais e marcas.

Fonte do jogo: https://rafael-hunter-game-comp.itch.io/a-nightmare-on-elm-street-last-dawn
